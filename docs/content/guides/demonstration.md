# Faire une démonstration

Scénario de 15 minutes pour présenter la plateforme.

1. **Interface** (1 min) : bandeau, trois horloges (UTC, Paris, Cayenne), compteurs P1/P2/SLA.
2. **Carte** (3 min) : ZEE, limites SHOM, aires protégées ; flèches AIS colorées par catégorie ; surcouche **Courants** puis **Température** (fronts) ; lumières nocturnes VIIRS.
3. **Scan radar** (3 min) : *Scanner* la dernière scène ; commenter les étapes affichées ; ouvrir la cible la plus risquée : vignette, fiabilité, raisons du risque, imagerie autour.
4. **Incident** (3 min) : *Prendre en charge*, playbook, note, *Qualifier* ; avec un compte superviseur : *Escalader* vers le CROSS, puis voir la notification sur la page /notifs/ de la console.
5. **Fusion** (2 min) : cliquer un navire AIS étranger → fiche fusion (flux, GFW Insights, sanctions).
6. **Preuves** (2 min) : *Vérifier* → Preuve intègre ; *Exporter* le ZIP ; *Audit* → « Chaîne intègre ».
7. **Documentation** (1 min) : onglet *Documentation*, recherche d'un terme.

!!! tip "Préparer"
    Clés Copernicus, aisstream et GFW configurées la veille (l'historique AIS met quelques heures à se constituer) ; deux comptes (analyste, superviseur) ; un scan déjà réalisé si le réseau est incertain.
