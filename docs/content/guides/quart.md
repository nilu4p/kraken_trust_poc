# Prise et fin de quart

## Prise de quart (10 minutes)

- [ ] **Bandeau** : noter le nombre de P1 / P2 ouverts et de **SLA** dépassés.
- [ ] **Couverture** (*Situation → panneau Contexte → Couverture temporelle*) :
    - AIS continu **vert** (dernier signal < 15 min) — sinon prévenir l'administrateur : sans AIS, les échos radar ne peuvent pas être triés et les règles 24/7 sont aveugles ;
    - date du **dernier scan radar** ; s'il date de plus de 48 h et qu'un passage a eu lieu, lancer un scan ;
    - règles 24/7 exécutées il y a moins de 2 minutes.
- [ ] **Santé des sources** (administrateur) : aucune source « hors service ».
- [ ] **Incidents → Non assignés** : se répartir les incidents ouverts (bouton *Me l'attribuer*, ou affectation par le superviseur).
- [ ] **Incidents → SLA dépassés** en priorité (colonne *SLA* en rouge).
- [ ] Lire le canal **#alertes** depuis la fin du quart précédent.
- [ ] **Commandement → Moyens** (superviseur) : disponibilité de chaque moyen à jour (*Disponible*, *Engagé*, *Indisponible*) — l'aide à la décision en dépend.
- [ ] Lire le dernier **SITREP** (*Commandement → Rapports émis*).

## Pendant le quart

- Traiter les P1 dans les 30 minutes (délai de triage), les P2 dans les 2 heures.
- Documenter chaque décision dans la **chronologie** (champ *Ajouter une note d'analyse*) : le collègue suivant doit comprendre sans vous appeler.
- Classer immédiatement les **fausses alarmes** : la plateforme apprend.
- Avant de demander un engagement, consulter l'**Aide à la décision** du dossier puis émettre un **compte rendu** signé ([Rendre compte](rendre-compte.md)).

## Fin de quart

- [ ] Aucun incident « Nouveau » sans prise en charge.
- [ ] Pour chaque incident en cours : une note de passation (« attente imagerie Pléiades », « Marine saisie, réf. … »).
- [ ] Réaffecter les incidents personnels au quart suivant (superviseur) ou les laisser *Non assignés* avec une note.
- [ ] Émettre le **SITREP** de la période (superviseur) : *Commandement → SITREP*.
- [ ] Se **déconnecter**.
